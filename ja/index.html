[ 01 ]概要

About

AI ツールを設計する、東京のテクニカルプロデューサー。写真家でもあります。

Ishinuki Daikie です。アイデアを、実際に人が使うものへ変えていくことが好きな開発者です。テキサス大学ダラス校でコンピュータサイエンスを学び、React・Next.js から Node/Express、PostgreSQL、REST API まで幅広く手がけています。現在は SeenThis Japan のテクニカルプロデューサーとして、広告素材をオープンウェブのディスプレイ広告へ制作・変換しています。これまでに300件を超えるキャンペーンとモックアップを、制作から配信まで一貫して担当してきました。キャンペーン制作と並行して、チームが使う AI ツールも設計しています。Night-Shift Studio は夜のうちに広告の方向性を下書きし、プロダクションキットは制作ルールを AI が守れる形にまとめたものです。どちらも仕様を書き、Claude Code で構築しています。

ダラスを経て、東京を拠点にしています。UTD 卒業後に来日し、創価大学で日本研究のポストグラデュエート・プログラムを修了しました。英語はネイティブ、日本語は日常会話レベル（JLPT N3）です。写真は趣味を超えた実践で、エンジニアとしての自分とアーティストとしての自分が出会う場所です。
