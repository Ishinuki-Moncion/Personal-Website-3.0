## Method note
Type is a **legibility + rhythm** surface, not a scene surface. The board pairs
(a) real EN/JP graphic design + type-in-use specimens (weight/size pairing,
tracking, mono grids, JP-as-texture) with (b) FUI / game-menu type (label
grammar, technical numerals). Site bearing (no code change): `css/site.css`
`--font-display: Hanken Grotesk` (wt 200, negative tracking on headings),
`--font-mono: JetBrains Mono` (wide +tracking 0.1-0.35em, uppercase, 9-13px,
ALL HUD labels/tags/coords), `--font-jp: M PLUS Rounded 1c` (`.mm-ja` muted,
small, pushed to margin as accent). **Host learnings:** `fontsinuse.com` is the
primary source and fully curl-able via `assets.fontsinuse.com` (append
`upto-700xauto` in place of `thumb` in the path to get study-res renders) and
`original.fontsinuse.com`. `mir-s3-cdn-cf.behance.net` images curl clean (HTTP
200, browser UA). `interfaceingame.com` screenshot pages 403 to WebFetch — game
menu type was sourced from fontsinuse's CP2077 gallery instead. Font IDs below
are per the fontsinuse attributions (tier [EXTRACTED]), not independently
verified. No parallel fan-out; single-threaded per the plan.

## Principles
Tier legend: [VERIFIED] cross-checked across >=3 board refs · [EXTRACTED] read directly off one primary reference · [DATA] measured pixel value · [WORKING] practitioner judgment/extrapolation, no measurement.

1. [VERIFIED] **Two type registers, kept strictly apart.** A tracked UPPERCASE label/chrome voice (small, wide letterspacing) carries UI furniture; a sentence-case reading voice (larger, looser, colored) carries body/narrative. Cross-checked: CP2077 sets nav tabs, list titles and tags in tracked caps while quest briefings run sentence-case; the CP2077 website repeats it (tracked-caps nav/ticker/pills vs sentence-case body); the Cockroach-Party site wraps a display headline in mono ticker/nav/pill chrome. For daikieOS this IS the Hanken-vs-JetBrains-Mono split — enforce it: never set body copy in the mono label voice, never set a label in the reading voice. (ref: 002-cp2077-ui1, 004-cp2077-orbitron-numerals, 014-jbmono-editor; src: https://fontsinuse.com/uses/60926/cyberpunk-2077-video-game)
2. [EXTRACTED] **Pair label + value by inverting weight and size, not color alone.** The label is small tracked caps; the value is 2-4x larger and brighter and carries the meaning. CP2077 sets a tiny "POSITION" above a huge "1/6", "RACE TIME" above "02:19:09", and "45 LEVEL / 50 STREET CRED" as big-numeral-over-small-caps. The number is the hero; the label just names it. Apply to daikieOS stat/coord readouts: shrink+track the label, enlarge+brighten the value. (ref: 001-cp2077-menu-rajdhani, 003-cp2077-ui2; src: https://fontsinuse.com/uses/60926/cyberpunk-2077-video-game)
3. [VERIFIED] **Tabular (fixed-width) figures for anything that aligns in a column or ticks live** — so digits never reflow. Cross-checked: CP2077's stat screen right-aligns a numeral column ("100 Oxygen / 578 Carrying Capacity / 4.20 Movement Speed / 77% Visibility"); the charm/Glow terminal aligns "9001 / 9002 / 10000" under a POWER rule; the ei-12437 menu column-aligns "€5 €9 €11 €14 €17". JetBrains Mono is already monospaced — keep coords, indices, stats and clocks in it, not in Hanken; prefer a face whose zero is disambiguated (slashed/dotted) and whose 1/l/I are distinct. (ref: 003-cp2077-ui2, 015-jbmono-code, 017-tabular-dashboard; src: https://fontsinuse.com/tags/14097/tabular-numerals)
4. [EXTRACTED] **Give hero/signal numbers a distinct geometric "techno numeral" treatment** so they read as machine output, not text. CP2077 sets "CONNECTION 201.89.43" and the big "010 0937" in a wide geometric face (Orbitron) separate from the Rajdhani labels around them. On daikieOS a single accent treatment (wider tracking / larger optical size in the mono) can mark "system" numbers vs ordinary ones — use ONE, sparingly, or it stops signalling. (ref: 005-cp2077-holo-screen, 004-cp2077-orbitron-numerals; src: https://fontsinuse.com/uses/60926/cyberpunk-2077-video-game)
5. [VERIFIED] **Track labels wide and even; the smaller the label, the more tracking it needs** to stay legible and read as "instrument." Cross-checked across the CP2077 HUD/nav, the Cockroach ticker+nav+pill, and the ei-12437 footer nav — every small caps label is generously letterspaced. This matches the site's own 0.1-0.35em; keep tracking proportional to smallness (tiniest 9-10px labels get the widest ~0.2-0.35em, larger caps back off toward 0.1em). (ref: 001-cp2077-menu-rajdhani, 014-jbmono-editor, 017-tabular-dashboard; src: https://fontsinuse.com/typefaces/171187/jetbrains-mono)
6. [EXTRACTED] **The monospace grid is a legibility+alignment tool, not decoration.** Box-drawing rules, a code/terminal column, and restrained syntax color let a mono face carry dense technical content cleanly. The charm/Glow terminal renders a NAME|POWER|COMMENT table with mono glyphs + rules and keywords/strings in distinct hues. For daikieOS, when showing code-like or tabular data, lean on JetBrains Mono's native grid (column rules, a couple of syntax hues) rather than boxing every value in HUD chrome. (ref: 015-jbmono-code; src: https://fontsinuse.com/typefaces/171187/jetbrains-mono)
7. [VERIFIED] **When JP is the content/hero, compress it and pack it edge-to-edge on max contrast** — the glyphs ARE the composition. Cross-checked across three Evangelion title cards: "使徒、襲来" and "嘘と沈黙" set huge in a mechanically-condensed display serif (Matisse EB), pure black-on-white or white-on-black, filling the frame. Hero JP should be large, tight, high-contrast and own its space — not a polite caption. (ref: 006-eva-titlecard-jp, 007-eva-titlecard15, 008-eva-eoe-titlecard; src: https://fontsinuse.com/uses/28760/neon-genesis-evangelion)
8. [EXTRACTED] **Set the section/index tag small and VERTICAL beside the big horizontal title** — a quiet index mark that also signals "Japanese." Evangelion sets "第壱話 / 第拾伍話" vertically at the left margin of each title card; Akira stacks アキラ vertically as an alternate. This legitimizes a small vertical JP/kana index mark (a section number set 縦書き) as an accent beside a horizontal EN heading on daikieOS. (ref: 006-eva-titlecard-jp, 007-eva-titlecard15, 012-akira-cover; src: https://fontsinuse.com/uses/28760/neon-genesis-evangelion)
9. [EXTRACTED] **Katakana can carry a title as an aggressive angular/brush display in a single signal color — JP as bold content, not ornament.** Evangelion Rebuild sets "ヱヴァンゲリヲン新劇場版：破" in angular red katakana+kanji on black; Akira's alternate logo renders アキラ as a brush form. When JP should be LOUD, style the kana as display and give it the one accent hue (the site's amber, or a signal red) — never a body weight. (ref: 009-eva-rebuild-titlecard, 011-akira-latin-logo; src: https://fontsinuse.com/uses/18290/akira-by-katsuhiro-otomo)
10. [VERIFIED] **When Latin is the hero, JP rides as a compact secondary lockup** — smaller, set beside/beneath the Latin, adding texture and authenticity without competing. "THE END OF EVANGELION" runs large with a tiny JP subtitle beneath; "TEATRIP JAPAN" locks Latin serif caps with compact kanji 茶旅; Akira mastheads pair "AKIRA / OTOMO KATSUHIRO" with a micro genre tag. This is exactly the site's `.mm-ja` role — JP as the muted margin companion to the EN label. Keep JP-as-accent muted, small, and never louder than its Latin partner. (ref: 008-eva-eoe-titlecard, 019-jp-slanted-editorial, 013-akira-jp-detail; src: https://fontsinuse.com/uses/28760/neon-genesis-evangelion)
11. [EXTRACTED] **A locked bilingual masthead can repeat as an identity anchor over changing content, with a tiny genre/section tag on the top rule.** Akira's Young-Magazine title pages repeat the "AKIRA / OTOMO KATSUHIRO" lockup over every chapter, "第75回 / 本格SFアクション" set micro in the top strip. For daikieOS a fixed brand lockup + a small changing section tag keeps identity constant across sections — period-correct and cheap. (ref: 013-akira-jp-detail; src: https://fontsinuse.com/uses/18290/akira-by-katsuhiro-otomo)
12. [WORKING] **To signal "Japan" without literal kana, use one restrained graphic motif over Swiss/disciplined type.** "Japanese Design Since 1945" pairs plain Helvetica caps with a single rising-sun sunburst on deep red — the motif carries the reference so the type can stay neutral. On daikieOS the cyan-on-dark globe/limb (or a rising-sun radial) can hold the "Japan/orbit" reference while type stays disciplined. Use ONE motif, never a pile of "Japanese-y" ornament. (ref: 020-jp-design-cover; src: https://fontsinuse.com/tags/1623/japan)
13. [EXTRACTED] **Optically balance short kana/kanji runs by resizing individual glyphs** — even lettering artists hand-tune, they don't set flat. Akira's designer enlarged the キ in アキラ "so the three characters balance." When setting a short kana/kanji accent on daikieOS, trust optical size over metric equality: nudge per-glyph sizes so the run reads even. (ref: 012-akira-cover, 011-akira-latin-logo; src: https://fontsinuse.com/uses/18290/akira-by-katsuhiro-otomo)
14. [WORKING] **Micro-text as texture, never as content.** CP2077 scatters tiny near-illegible mono strings (protocol codes, coordinates) at frame edges purely as "the system is alive" density. Keep such texture faint, monospaced and clearly subordinate so it reads as atmosphere — if a user has to squint to parse it, it must not matter that they can't. (ref: 003-cp2077-ui2, 001-cp2077-menu-rajdhani; src: https://fontsinuse.com/uses/60926/cyberpunk-2077-video-game)

## Thin areas / open questions
- **No [DATA] measurements.** Exact tracking em-values, weight numbers (Rajdhani Regular/Medium/SemiBold/Bold), and label-to-value size ratios are read qualitatively ([EXTRACTED]/[VERIFIED]); a [DATA] pass would need pixel measurement of cap-heights and letterspacing. Consistent with the library's known no-measurement debt — not invented here.
- **Font IDs are [EXTRACTED], not [VERIFIED].** Rajdhani/Orbitron/Blender/Refinery (CP2077), Matisse EB / Helvetica / Times (Evangelion), and Schmalfette/Impact (Akira) are per the fontsinuse post attributions, not independently confirmed against the shipped assets.
- **interfaceingame.com is a gap.** Its screenshot pages 403 to WebFetch, so a dedicated game-menu capture (e.g. a Ghost of Tsushima bilingual JP/EN main menu — an ideal EN/JP pairing at UI scale) was not taken; CP2077 menu type via fontsinuse covered the FUI-type need. Capture GoT via the MCP-browser fallback if the elevation brief needs a real bilingual game menu.
- **Long-form vertical JP (縦書き) untested.** Only short vertical index tags (episode numbers) were sampled; a long vertical-set body passage was not.
- **Pure kana-as-wallpaper texture** is inferred from CP2077 Latin micro-text + Akira mastheads; a clean specimen of dense kana used purely as background texture wasn't captured (Behance CDN is curl-able if a dedicated pass is wanted).
- **Two off-brief frames removed:** 016 (Garage-Museum diagonal Cyrillic — the source filename "01-clock" was misleading; not tabular numerals, not EN/JP) and 018 (a Latin deco display face named "Katakana" — Latin glyphs, not Japanese).
