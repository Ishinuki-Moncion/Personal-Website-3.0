Why a separate test bench

The globe is the centrepiece of the portfolio, which makes it the worst place to experiment. This repository lets me change the scene on its own, with no page animation, scroll effects or startup sequence in the way.

It runs from any static web server with no build step, so the scene is the only thing that changes.

An Earth made only of land

The globe is a cloud of points. A land map built from Natural Earth's 1:110m land outlines decides which points to keep.

The map is a 384×192 grid of land and sea, stored in the source code and decoded once at startup.

So the coastlines are easy to recognise, and the oceans stay truly empty. The shape reads as coastline.

Motion that costs nothing per frame

The GPU computes the points' gentle pulse from a single time value. Nothing is uploaded each frame, there is no per-point work on the CPU, and the cost does not grow with the number of points.

The Dallas-to-Tokyo arc is a curve along the globe's surface between the two cities. It appears by drawing a little more of the same shape each frame, and the shape is never rebuilt.

Its speed follows real time, so it moves the same at any frame rate.

When the browser stops cooperating

The animation pauses when the tab is hidden and resumes without starting twice. If the browser loses the 3D context, the page handles it and does not freeze.

With reduced motion on, the globe shows one still frame that tells the same story: Tokyo turned toward the viewer, and the arc fully drawn.
