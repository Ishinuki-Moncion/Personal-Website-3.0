[ 01 ]概要

About

東京を拠点とする開発者・写真家。

Ishinuki Daikie です。アイデアを、実際に人が使うものへ変えていくことが好きな開発者です。テキサス大学ダラス校でコンピュータサイエンスを学び、React・Next.js から Node/Express、PostgreSQL、REST API まで幅広く手がけています。現在は SeenThis Japan のテクニカルプロデューサーとして、広告素材をオープンウェブのディスプレイ広告へ制作・変換しています。これまでに100件を超えるキャンペーンを、制作から配信まで一貫して担当してきました。

ダラスを経て、東京を拠点にしています。UTD 卒業後、日本への関心をさらに深め、創価大学で日本研究のポストグラデュエート・プログラムを修了しました。英語はネイティブ、日本語は日常会話レベル（JLPT N3）です。写真は趣味を超えた実践で、エンジニアとしての自分とアーティストとしての自分が出会う場所です。

ROUTE // PERSONAL VECTOR Dallas → Tokyo 背景の地球儀も同じ移動を描いています。UTD とダラスを起点に、開発・制作・写真の現在地である東京へ。
