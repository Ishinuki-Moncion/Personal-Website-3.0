The work

Ad creative arrives as design files and video. It has to leave as display ads that run on the open web: real HTML, CSS and JavaScript.

Each ad must fit a strict file-size budget. It must also work across many placements and devices it was never designed for.

Since March 2025 I have taken more than 300 campaigns and mockups through that process, from first build to launch.

What the limits teach

Display ads are an honest test of performance. The size budget is small and fixed, the ad runs on someone else's page, and no visitor will wait for it. Every kilobyte has to earn its place.

Working inside that budget at volume taught me to measure what a page actually sends. It also taught me that delivering files is its own job, separate from design.

Volume changes the problem

With one campaign, the interesting question is the creative. With a hundred, it is the process.

Some work is truly different each time. Some is the same every time. And some only looks the same until it fails.

That pressure pushed me to build tools for the repetitive parts. A production pipeline should make the correct result the easy one, so quality does not depend on care at every step.
